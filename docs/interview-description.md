# Как представить проект на собеседовании

Это автономный учебный проект автоматизации тестирования B2B streaming-платформы. Внутри находится локальное web-приложение на JavaScript, REST API на Express и Cypress-тесты на TypeScript.

Основная цель проекта заключалась в создании стабильного e2e-набора, который не зависит от внешних стендов. Для этого тестовый продукт и API запускаются локально вместе с тестами.

В проекте реализованы UI и API проверки, Page Object, fixtures, custom commands, перехват запросов через `cy.intercept`, негативные сценарии, проверка кодов ответа и JSON, mobile viewport, smoke-набор и CI-конфигурации.

Наиболее показательные сценарии

- Авторизация с проверкой UI и сетевого ответа
- Проверка REST API через `cy.request`
- Поиск и фильтрация каталога
- Добавление и удаление сущности из избранного
- Подмена ответа API через fixture
- Проверка поведения интерфейса при ответе 500
- Проверка адаптивного отображения

Проект показывает умение организовать структуру автоматизации, отделять page objects от тестов, переиспользовать команды, контролировать тестовые данные и запускать проверки в CI.
