# Основные тест-кейсы

## TC-001 Успешная авторизация

Предусловия

Пользователь находится на странице входа.

Шаги

1. Ввести `qa@stream.local`.
2. Ввести `Qwerty123!`.
3. Нажать `Sign in`.

Ожидаемый результат

Открывается каталог. В localStorage сохраняется токен. Отображаются три трансляции.

## TC-002 Неверный пароль

Шаги

1. Ввести зарегистрированный email.
2. Ввести неверный пароль.
3. Нажать `Sign in`.

Ожидаемый результат

API возвращает 401. Пользователь остается на форме входа. Отображается сообщение об ошибке.

## TC-003 Фильтрация каталога

Шаги

1. Авторизоваться.
2. Выбрать статус `Maintenance`.

Ожидаемый результат

Отображается только трансляция `City Live`.

## TC-004 Добавление в избранное

Шаги

1. Авторизоваться.
2. Нажать `Add favorite` у `Ocean Depths VR`.
3. Выполнить GET `/api/favorites`.

Ожидаемый результат

Кнопка меняет состояние. API возвращает одну запись с id `stream-101`.

## TC-005 Ошибка загрузки каталога

Шаги

1. Подменить ответ GET `/api/catalog` на 500.
2. Открыть приложение.

Ожидаемый результат

Карточки не отображаются. Пользователь видит понятное сообщение об ошибке.
