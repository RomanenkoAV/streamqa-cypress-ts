# Пример баг-репорта

## Заголовок

[Web][Catalog][High] После ответа 500 каталог остается пустым без возможности повторной загрузки

## Окружение

- Windows 11
- Chrome 149
- Build 1.0.0
- Test environment

## Предусловия

Пользователь авторизован. Endpoint `/api/catalog` временно возвращает 500.

## Шаги

1. Открыть каталог.
2. Дождаться ответа 500 от `/api/catalog`.
3. Восстановить доступность API.
4. Нажать `Refresh`.

## Фактический результат

Сообщение об ошибке остается на экране. Каталог не загружается повторно.

## Ожидаемый результат

После нажатия `Refresh` выполняется новый запрос. При ответе 200 каталог отображается, сообщение об ошибке скрывается.

## Severity

Major

## Priority
