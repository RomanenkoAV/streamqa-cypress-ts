# Тест-план

## Цель

Проверить ключевые пользовательские и интеграционные сценарии демонстрационной B2B streaming-платформы. Проект охватывает UI, REST API, обработку ошибок сети, адаптивность и базовую проверку контрактов.

## Объекты тестирования

- Авторизация партнера
- Каталог VR-трансляций
- Поиск и фильтрация
- Добавление трансляции в избранное
- REST API каталога и избранного
- Обработка ответов 4xx и 5xx
- Адаптивное отображение интерфейса

## Виды тестирования

- Smoke
- Функциональное
- Регрессионное
- Интеграционное
- API
- Негативное
- Кроссбраузерное
- Адаптивное

## Приоритеты

P0

- Доступность приложения
- Успешная авторизация
- Загрузка каталога

P1

- Поиск и фильтрация
- Избранное
- Обработка ошибок API

P2

- Адаптивность
- Дополнительные проверки схемы ответа

## Критерии входа

- Приложение запускается локально
- API отвечает на `/api/health`
- Тестовые данные доступны
- Cypress установлен

## Критерии выхода

- Все smoke-тесты пройдены
- Нет открытых дефектов Blocker и Critical
- Успешно пройден регрессионный набор
- Результаты тестов и артефакты сохранены в CI
